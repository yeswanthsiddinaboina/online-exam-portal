Technical Engineering

System Architecture & Technology Stack

Client-Side Edge AI (Browser)
LOW BANDWIDTH

HTML5, WebRTC camera feed, MediaPipe Face Mesh (468 3D landmarks), Canvas API. Edge execution analyzes 30 fps video locally without streaming high-bandwidth video across the network.

Backend API & Security Services
HIGH CONCURRENCY

Python 3, Flask RESTful API, PyJWT token authentication, PBKDF2/Argon2 password hashing, and active heartbeat session managers that prevent multi-tab sessions.

Database & Storage Layer
CLOUD READY

Neon Serverless PostgreSQL with auto-scaling connection pooling (with local SQLite fallback), self-healing migrations, and disk snapshot evidence management.

Key Architectural Advantages
✓ Pure-Python PDF Generation: Zero external dependencies (no ReportLab/wkhtmltopdf). Generates high-fidelity PDF 1.4 directly from memory in <100ms.
✓ Edge Vision Scalability: Because video processing is performed client-side, 10,000 students can test concurrently on a modest cloud server without CPU spikes.
✓ Self-Healing Schemas: Dynamic column additions (e.g. phone numbers, course categories) migrate automatically across local and production DBs.
✓ Complete Cascade Cleanup: Deleting an attempt or student purges all foreign keys, results, logs, and disk images to prevent database bloat.

Computer Vision Innovation

Calibrated 3D Head Pose & Face Intelligence

468 3D Landmark Mesh

Tracks key facial anchors (nose tip, chin, eye corners, mouth bounds) in real time at 30 fps. Solves Perspective-n-Point (PnP) pose calculations to determine exact head angles.

The 75° Calibrated Threshold

Specifically tuned to eliminate false positives. Natural eye scanning across ultra-wide monitors is tolerated; looking away at an accomplice or second monitor past 75° triggers a non-intrusive violation warning.

Face Verification & Anti-Impersonation

Pre-exam webcam snapshot matches the registered candidate photo. Continuous facial presence checks guarantee no unauthorized substitute takes over mid-exam.

📐 ➔ 👤
Precision Angle Detection

Our mathematical rotation vector calculates Euler Yaw (ψ). Infractions are triggered strictly when |Yaw| > 75°.

Security & Integrity Enforcement

Environmental Lockdown & Anti-Tamper

🖥️
Fullscreen Enforcement
Candidate cannot view questions without entering fullscreen. Exiting fullscreen triggers an immediate modal lockout and logs a security infraction.
🔀
Tab-Switch Interception
Page visibility API and window blur events intercept any attempt to search Google, open ChatGPT, or switch applications.
🛑
Automated Termination
Configurable violation strike limits (e.g., 5 strikes). Upon exceeding limits, the exam is instantly terminated and marked MALPRACTICE_CANCELLED.
📋
Clipboard Protection
Right-click context menu, text selection, copy (Ctrl+C), paste (Ctrl+V), and developer inspection shortcuts (F12, Ctrl+Shift+I) are intercepted and suppressed.
💓
Active Heartbeat Polling
Continuous cryptographic heartbeats sent every 10 seconds. Disconnecting or running parallel browser sessions terminates the candidate's session token.
📸
Instant Evidence Snapshots
Every logged violation captures an encrypted timestamped webcam frame stored securely for post-exam review and administrative audit.

Domain Isolation & Onboarding

Course-Based Isolation & Candidate Control

1
Streamlined Candidate Registration

Candidates register with Full Name, Verified Gmail, 10-digit Phone Number, and their designated course (Python, Java, Drive). Phone numbers are stored with self-healing DB migrations.

2
Airtight Exam Isolation (Exam.is_accessible_by)

Exams created for 'Drive' are accessible strictly to Drive students. Direct URL manipulation or API tampering is rejected with 403 EXAM_COURSE_MISMATCH.

3
Distinctive Visual Badging

Streamlined purple badges for 'Drive' candidates and exams across both Student and Admin portals ensure zero administrative mix-ups during multi-track recruitment drives.

4
Granular Access Request Lifecycle

Approved students request access to designated exams. Admins approve access individually or with our bulk 'Approve All' feature.

Example: "Drive" Campus Recruitment
DRIVE BATCH

Enables hiring companies to run private corporate drives in parallel with regular academic testing without sharing question banks or candidate rosters.

Instant Re-Registration Workflow

Admins can permanently delete any candidate. Our cascade deletion clears the student user, exam attempts, answers, violations, access permissions, and disk photos, allowing the student to re-register fresh immediately with the same email.
